Como Acessar?

Opção 1: Abrir Direto (Mais Rápido)

✅ Procure por index.html na pasta do projeto
✅ Clique duas vezes ou arraste para o navegador

Opção 2: Com Servidor Local (Recomendado)

1. Abra PowerShell ou CMD
2. Digite um dos comandos abaixo:
💠 Se tiver Python:

python -m http.server 8000

Depois acesse: http://localhost:8000
💠 Se tiver Node.js:

npx http-server

Depois acesse: http://localhost:8080
